# Day 03 – Student Performance Data Analysis

## Objective

The objective of this task is to analyze a student performance dataset using Python and Pandas. The analysis includes data exploration, data cleaning, statistical calculations, filtering, correlation analysis, and data visualization to extract meaningful insights.

## Task Requirements

The following tasks were completed:

* Load the student performance dataset.
* Display basic information about the dataset.
* Calculate average scores.
* Identify students with the highest and lowest scores.
* Find students with attendance below 75%.
* Identify students who are at risk of failing.
* Calculate the average final score for each course.
* Analyze the relationship between attendance and final score.
* Handle missing values in numerical and categorical columns using appropriate techniques.
* Create data visualizations for better understanding of the dataset.

## Technologies Used

* Python 3
* Pandas
* Matplotlib
* Jupyter Notebook

## Dataset Features

The dataset contains the following columns:

* Student Name
* Age
* Gender
* Course
* Attendance
* Assignment Score
* Midterm Score
* Final Score

## Data Preprocessing

The following preprocessing steps were performed:

* Checked dataset information and summary statistics.
* Identified missing values.
* Filled missing numerical values using the median.
* Filled missing categorical values using the mode.
* Verified that no missing values remained after preprocessing.

## Data Analysis Performed

* Dataset overview
* Descriptive statistics
* Student filtering based on attendance
* Highest and lowest score analysis
* Average score calculations
* Course-wise average final scores
* Attendance and final score correlation analysis
* Identification of at-risk students

## Data Visualizations

The notebook includes the following visualizations:

1. Final Score Distribution (Histogram)
2. Average Final Score by Course (Bar Chart)
3. Attendance vs Final Score (Scatter Plot)
