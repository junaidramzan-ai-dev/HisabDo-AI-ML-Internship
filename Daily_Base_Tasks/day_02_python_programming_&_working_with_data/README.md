# Day 02 – Student Data Analysis

## Objective

The objective of this task is to create a student dataset using Python, convert it into a Pandas DataFrame, and perform basic data analysis operations.

## Task Requirements

* Create a dataset containing at least 10 students with the following information:

  * Name
  * Age
  * Course
  * Marks
* Convert the dataset into a Pandas DataFrame.
* Perform the following operations:

  1. Display all students.
  2. Display students with marks greater than 70.
  3. Calculate the average marks.
  4. Find the student with the highest marks.
  5. Find the student with the lowest marks.
  6. Display the total number of students.
